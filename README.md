# ZoomBlog — قالب مجله و بلاگ فارسی وردپرس

قالبی سبک، حرفه‌ای و **فارسی‌محور** برای بلاگ و مجله، الهام‌گرفته از زومیت — با RTL کامل، حالت روشن/تیره/سپیا، تاریخ جلالی، فارسی‌ساز (ی/ک، نیم‌فاصله)، تجربهٔ خواندن پریمیوم و سازگاری کامل با **Elementor / Elementor Pro** و **Rank Math / Yoast**.

A lightweight, Persian-first WordPress magazine & blog theme inspired by Zoomit.

---

## ✨ در یک نگاه

- 🎨 سیستم طراحی مدرن ۲۰۲۶ با توکن‌های CSS و حالت **روشن / تیره / سپیا**
- 🇮🇷 تجربهٔ کاملاً بومی: **تاریخ جلالی**، یکسان‌سازی `ی/ک`، مدیریت **نیم‌فاصله**، پیشنهاد واژهٔ نزدیک
- 🔤 قلم **وزیرمتن محلی** (بدون گوگل فونت) با پیش‌بارگذاری کنترل‌شده
- 📖 نوار پیشرفت، **فهرست مطالب**، زمان مطالعه، **مرکز کنترل خواننده**، ادامهٔ مطالعه، تاریخچه
- 🔖 بوکمارک، ❤️ لایک، 👤 دنبال‌کردن نویسنده، 👍 درصد پیشنهاد
- 🧱 صفحات آماده: آرشیو، دسته، نویسندهٔ حرفه‌ای، جست‌وجوی زنده، ۴۰۴
- ⚙️ پنل تنظیمات **قابل جست‌وجو**، گروه‌بندی‌شده، با بازنشانی هر بخش
- 🧰 ابزار **سلامت محتوا**، **آمار تحریریه**، **کارت اجتماعی**، **ویزارد نصب ۶ مرحله‌ای**
- 🧩 سایدبار مرتب هر نوشته (گوتنبرگ و کلاسیک)
- 🚀 بارگذاری شرطی CSS/JS، بدون jQuery، سازگار با کش و CDN، WebP/AVIF
- 🔒 پی‌وال سبک، 📣 مدیریت تبلیغات با رزرو فضا (ضد CLS)

## 📦 نصب سریع

پوشه را در `wp-content/themes/zoomblog` قرار دهید و فعال کنید، سپس **زومبلاگ ← نصب سریع** را اجرا کنید.

## 📚 مستندات

راهنمای کامل فارسی: [`docs/DOCUMENTATION-fa.md`](docs/DOCUMENTATION-fa.md)

## 🗂 ساختار

```
zoomblog/
├─ *.php                 قالب‌های وردپرس (single, home, archive, …)
├─ template-parts/       اجزای قابل استفادهٔ مجدد (card, hero, toc, …)
├─ inc/                  منطق تم (persian, jalali, enqueue, seo, …)
│  └─ admin/             پنل تنظیمات، ویزارد، سلامت محتوا، آمار، کارت اجتماعی
├─ assets/
│  ├─ css/               استایل‌های بخش‌بندی‌شده (بارگذاری شرطی)
│  ├─ js/                جاوااسکریپت بدون وابستگی
│  └─ fonts/vazirmatn/   قلم محلی (OFL)
├─ docs/                 مستندات فارسی
└─ theme.json            توکن‌های سراسری و تنظیمات ویرایشگر بلوک
```

## ⚖️ مجوز

کد قالب تحت **GPL v2 یا بالاتر**. قلم وزیرمتن تحت **SIL OFL 1.1** (فایل `assets/fonts/vazirmatn/OFL.txt`).
